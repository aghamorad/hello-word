# Changelog

## Private test refinement

- Rebuilt Midnight Library as a luminous, inhabitable circular reading room and retuned its typography and controls for the pale honey background.
- Replaced Still's abstract rings and waves with a pale misted lake whose center and lower field recede behind the prose.
- Squared and levelled the Typewriter paper while preserving the existing Havana room, and mapped the editor vertically to the visible sheet at every window aspect ratio.
- Made themed menu hover state exclusive so a highlight cannot trail from one world choice into another.

## 0.5 — First public preview

- Added native Find and Replace, Find Next/Previous and Use Selection for Find; `Command–F` now works.
- Turned the drawn Macintosh 1999, System 95 and DOS affordances into real clickable commands.
- Replaced Jellybean Arcade entirely with **Cyberdeck 2088**, a neon city/deck environment with readable mono type, cybernetic keys and dark analog ambience.
- Added the tenth world, **Hell**, as a grave painterly underworld with Pandemonium, iron sounds and a high-contrast writing sanctuary.
- Added separate Apple-silicon and Intel builds with architecture-matched offline Harper helpers.

- Renamed the app **Hello, Word** and added a one-second introductory splash card.
- Rebuilt all ten environments as complete, room-filling writing worlds.
- Added adjustable, invisible writing width, physical-surface limits and theme-specific fading controls.
- Added genuine native transparency, reflection and a full-opacity starting point to Liquid Glass.
- Added full-screen entry from the controls, menu, keyboard and background double-click.
- Added ten original three-minute ambient placeholders and per-world user music folders.
- Added a distinct generated sound instrument for every room, including a mechanical lever/carriage/ratchet/platen Return sequence for Typewriter.
- Added a themed in-world font chooser with search, sizing and bilingual English/Persian preview.
- Replaced the Typewriter, Midnight Library and Hell backdrops with original painterly worlds.
- Added bundled offline contextual English correction through Harper.
- Added automatic Persian/RTL paragraphs and room-aware Persian font selection.
- Added interactive footnotes with linked source/note markers.
- Localized Persian footnotes as RTL **پانویس** with Persian numerals.
- Added the retro Bondi-era Mac application icon.
