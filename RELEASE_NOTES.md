# Hello, Word 0.5 — first public preview

I made Hello, Word because I wanted a writing app whose simplicity did not mean emptiness: ten complete worlds, a writing boundary that can widen or disappear, controls that belong to the room and then fade away, sounds that support the work, private contextual correction, proper Persian/RTL behavior, and footnotes for the one person who decides to write an article in a typewriter floating above a planetary horizon.

This first public release includes separate Apple-silicon and Intel builds:

- ten immersive full-window writing environments, including the wonderfully unreasonable **Hell**;
- native Find and Replace with a working `Command–F`;
- clickable in-world menus in Macintosh 1999, System 95 and DOS;
- native full screen and adjustable writing width that respects the physical page or screen;
- a themed in-world font chooser with English/Persian preview;
- per-world keyboard instruments and quiet three-minute ambient loops;
- original painterly Typewriter, Midnight Library and Hell environments;
- genuine transparent and reflective Liquid Glass;
- local Harper-powered contextual English correction;
- automatic Persian/RTL paragraphs and Persian font selection;
- linked English footnotes and RTL **پانویس** with Persian numerals;
- TXT, Markdown and RTF open/save support;
- the retro Bondi-era Mac icon.

Download the archive marked **Apple Silicon** for M-series Macs or **Intel** for Intel Macs, open it, and move the app to Applications.

The builds are ad-hoc signed but not yet Apple-notarized. If macOS blocks the first launch, Control-click **Hello, Word.app**, choose **Open**, and confirm once. Both require macOS 13 or later.

The app has no login or analytics and does not upload writing. Harper runs locally. Please read the README for the full tour, known limitations, music-replacement folders and source map.

The ten included ambient tracks are placeholders. Each world has a folder button that opens its exact music folder in Finder; add an audio file you own or are permitted to use, and the first supported file alphabetically will replace the bundled loop. The README explains the formats, paths and folder names without requiring anyone to dig through the app bundle.
